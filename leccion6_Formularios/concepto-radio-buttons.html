Otros conceptos de los formularios

type="radio"

type radio: sirve para elegir una sola opcion entre varias


type "checkbox"

Checkbox: sirve para elegir varias respuestas

La diferencia es que radio solo permite una sola opcion, en cambio el checkbox permite varias opciones

type="date"

Nos permite pedir el tipo fecha, el navegador proporciona un selector de fecha

type="file"

Con el type="file" nos permite seleccionar un archivo
