Leccion 6 Formularios

¿Qué es un formulario?

Un formulario permite que el usuario introduzca informacion.

El elemento principal es <form> </form>

<input>

Es el elemento mas usado dentro de un formulario, el <input type="text"> crea un campo para texto

El <input type="email"> para correos electronico

El <input type="password">; es para el tipo contraseña

El <input type="number"
min="1"
max="100">
solo permite introducir numeros pero en este ultimo tambien se puede type="number" min="1" max="100" el cual le indicamos que el minimo es de 1 y maximo es de 100

label

El label sirve para indicar que informacion debe ingresar el usuario.

Por ejemplo:

<label>Nombre:</label>
<input type="text"> >

Existe una mejor forma de relacionar el label con el input.

<label for="nombre">Nombre:</label>

<input type="text" id="nombre" placeholder="Escribe tu nombre">

Aca creamos otro campo para la edad, al igual al anterior se uso <label for="edad">Edad:</label>

<input type="number" id="edad" placeholder="Escriba su nombre">
