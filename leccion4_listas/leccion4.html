ul significa unordered list = lista no ordenada y li significa List Item = Elemento de la lista

Lista Ordenada

Cuando el orden si importa, como recetas, manuales, tutoriales, pasos para instalar un programa

Ejemplo

  1. Despertar
  2. Ir al baño
  3. Bañarme
  4. Desayunar
  5. Ir al trabajo

Podemos cambiar la numeracion, por ejemplo en < ol type="A"> el resultado seria:

  1. HTML
  2. CSS
  3. JavaScript

Tambien podemos usar con "a" para poner en minuscula, y "I" en numeros romanos

  1. uno
  2. dos
  3. tres

Tambien podemos tener una lista dentro de otra
Ejemplo:

  • Lenguajes de Programacion:
    • Python
    • Java
    • C++
    • C#
  • Bases de Datos:
    • Postgresql
    • Oracle XE
    • Mysql
    • MariDB
